Internship Project
Multi Calculator

During my internship at SoftART,
I developed a calculator project in C# using WPF (Windows Presentation Foundation).
The project followed a Service-Oriented Architecture (SOA) and utilized the MVVM (Model-View-ViewModel) pattern.
It also supports computing and displaying various functions with the OxyPlot framework.
